4. Tone of Voice

  • Professional, confident, and precise
  • Technology-first but human
  • Clear, structured, and educational
  • Security and reliability focused

5. Design Principles

  • Minimalist layouts with strong visual hierarchy
  • Accent colors used only for actions and emphasis
  • Whitespace is functional, not decorative
  • Consistency across web, mobile, and hardware interfaces
  • Accessibility (contrast, size, readability) is mandatory

6. UI Components (Reference)

Buttons

Primary buttons use --ui-primary background with --text-inverse text.

Hover and active states use --ui-primary-hover and --ui-primary-active.


Secondary Buttons

Use --ui-secondary backgrounds with neutral borders.


Cards & Surfaces

Cards use --bg-surface. Widgets and panels may use --bg-widget.


Text & Icons

Primary text: --text-primary
Secondary text: --text-secondary
Disabled text: --text-disabled

7. UI Color Usage

  • Page backgrounds must use --bg-page
  • Never place text directly on accent colors without sufficient contrast
  • Status colors (success, warning, danger) are reserved for feedback only
  • Inverse UI is allowed only on dark or immersive screens
